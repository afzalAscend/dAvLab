# DAV Lab 1

Data Analysis and Visualization lab exercises using NumPy, Pandas, Matplotlib,
Seaborn, SciPy and scikit-learn.

| File | Topic |
| --- | --- |
| `01_numpy_pandas_indexing.ipynb` | DataFrame creation, indexing and slicing |
| `02_eda_operations.ipynb` | Exploratory data analysis and descriptive statistics |
| `03_graphs.ipynb` | Pie, scatter, box and histogram plots |
| `04_iris_analysis.ipynb` | Iris dataset exploration and plots |
| `05_outlier_detection.ipynb` | IQR and Z-score outlier detection and capping |
| `06_logistic_regression.py` | Binary classification with logistic regression |

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```

Put `exams.csv` and `IRIS.csv` in the `data/` folder (see `data/README.md`).
